# SMALL DESCRIPTION OF THIS PROJECT

This project will involve asking an input for the student names and grades until the user decided to quit the program and then 
the program will write the data inputted into a text file. 

MAIN CONCEPTS USED - FILE I/O, BUFFEREDWRITER AND SCANNER
